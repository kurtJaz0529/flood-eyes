## 第 1 页 · 封面

- 项目名：**慧眼识灾**——基于深度学习的遥感影像洪水淹没范围智能识别系统

- 团队名、成员、指导老师、学校、日期

## 第 2 页 · 痛点（用真实灾情开场）

- 2021 河南、2023 京津冀、2024 南方洪涝：受灾范围核定严重滞后
- 现状流程：卫星过境 → 人工目视解译 → 逐级上报，**1–3 天**
- 后果：错过黄金 72 小时；面积数据口径不一，保险定损争议大
- **一句话结论**：不是没有数据，是**没有把数据变成结论的能力**

## 第 3 页 · 我们的答案

- 输入：免费公开卫星影像（Sentinel-2 / 高分系列）
- 输出：像元级洪水范围 + 平方公里级面积 + 一页 PDF 简报
- 时间：分钟级（实测单景 640×640 约 0.7 秒，CPU 亦可）
- **视觉**：放演示 GIF（`docs/assets/demo_real_poyang.gif`）

## 第 4 页 · 技术架构（一张图讲完）

```
卫星影像 → 波段还原/NDWI → 512切片 → 双模型识别 → 后处理 → 面积统计 → 界面/简报
                                      ├ 基线 NDWI+Otsu
                                      └ U-Net 语义分割
```

- 强调：**双模型不是炫技，是"精度上限 + 零门槛兜底"的组合**

## 第 5 页 · 关键创新点 1：近红外物理闸门

- 问题：城市屋顶在 NDWI 上近似浅水 → 假阳性
- 解法：水体近红外反射率极低（<0.05），城市很高（>0.15），加模糊与门
- 效果（合成验证集）：**IoU 0.83 → 0.92，Precision 0.87 → 0.98**
- 图：同一景"开/关闸门"的对比图

## 第 6 页 · 关键创新点 2：双模型策略

| | 基线 NDWI+Otsu | U-Net 语义分割 |
|---|---|---|
| 需要 GPU | 否 | 训练需要，推理可 CPU |
| 需要训练数据 | 否 | 是 |
| 可解释性 | 强（阈值明确） | 中（可出概率热图） |
| 合成验证集 IoU | 0.92 | 0.97 |
| 定位 | 兜底 + 对照 | 精度上限 |

- 讲法：**"评委可以质疑深度模型，但没人能质疑一个能跑起来的兜底方案"**

## 第 7 页 · 关键创新点 3：工程可靠性

- 归一化统计量随权重保存 → 训练-推理一致
- 分块滑窗 + 重叠加权拼接 → 大图无接缝
- 退化场景保护：整景无信号、Otsu 失效自动降级
- 权重加载失败自动回落基线 → **演示不中断**
