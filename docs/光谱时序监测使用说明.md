# 本地多时相光谱监测

`python scripts/run_spectral.py` 可把按时间顺序排列的本地多景 GeoTIFF 自动配准到首景网格，计算每期指数和相邻两期差值，并写出带 CRS 的 GIS 栅格与 `summary.json`。此流程独立于洪水识别与批量任务库，不联网，也不会自动核验影像的观测日期。

## 适用方向

| 指数 | 所需波段 | 用途与边界 |
|---|---|---|
| NDVI | 红、近红外 | 植被绿度及相邻时相变化；下降不等于已确认的病害或灾损。 |
| SAVI（L=0.5） | 红、近红外 | 在植被稀疏、土壤背景影响较大区域观察绿度变化。 |
| NDWI（绿光/近红外） | 绿、近红外 | 地表水光谱指数的连续观测；指数变化不等于已确认的淹没面积。 |

公式分别为 `(NIR−Red)/(NIR+Red)`、`1.5×(NIR−Red)/(NIR+Red+0.5)`、`(Green−NIR)/(Green+NIR)`。这些指数只用项目已有的四波段数据。NBR 火烧迹地、NDMI 植被含水量等需要 SWIR，当前输入不能计算。

## 运行

从项目根目录执行（按影像真实拍摄时间排列）。下面使用仓库的合成演示影像，只用于检查流程：

```powershell
python scripts/run_spectral.py --index ndvi --images data/samples/demo01_pre.tif data/samples/demo01_post.tif --out-dir outputs/spectral_demo --min-valid-pct 50
```

若观测日期已由用户核对，可加 `--dates 2020-05-19 2020-07-15`，数量必须与影像数量一致且严格递增。未提供时摘要中的日期为 `null`，系统不会从文件名推断。指定日期只是用户声明，软件不会与卫星元数据交叉验证。三景或更多景会给出逐期指数和相邻两期差值；首景是固定参考网格。可通过 `--index savi` 或 `--index ndwi` 更换配方。每次显式指定的 `--out-dir` 必须是新目录，防止覆盖旧成果；省略此参数时程序自动建立唯一输出目录。

输入须有真实 CRS、仿射变换和所需波段。默认沿用 `src.preprocess.load_scene` 的波段描述解析及四波段 B2/B3/B4/B8 顺序；非该顺序的影像应提供正确描述或用 `--band-order` 指定。不同传感器或处理级别的影像不能仅靠空间配准就视为可直接比较。

## 质量与成果口径

- 每景指数 GeoTIFF 和相邻差值 GeoTIFF 使用 `float32`，`-9999` 表示无效；`0` 是合法指数值或零差值。
- 相邻两景的共同有效区 GeoTIFF 使用 `uint8`：`1=共同有效`、`0=无效`，`0` 不是 NoData。差值只在共同有效像元上计算。
- 存在同名 `_scl.tif` / `_scl.tiff` / `_scl.png` 时，剔除 SCL 0、1、3、8、9、10、11 类；没有 SCL 时会警告云、云影、雪及缺陷像元未完成筛除。GeoTIFF 侧车必须与主影像网格和 CRS 完全一致；PNG 只有尺寸可核对，需人工确认像素位置。摘要记录侧车路径与哈希。
- 单景或相邻两景共同有效比例低于 `--min-valid-pct` 时，统计值写成 JSON `null`，相邻差值栅格全为 NoData，不会报成零。摘要同时列出输入文件哈希、参数和质量原因。每景均值使用各自有效区；跨期变化请看仅使用共同有效区的相邻差值。
- 面积仅在米制投影且网格像元面积可计算时给出。指数差值是连续量；面积字段描述的是共同可观测范围，不代表植被损失或新增水域范围。

结果位于 `--out-dir`，其中 `summary.json` 是本次解释统计的入口。演示影像为合成数据，不支持真实精度声明；实际业务还需控制季节差异、传感器差异、云影与地形阴影，并结合现场或独立真值核验。

公式参考：[USGS NDVI](https://www.usgs.gov/landsat-missions/landsat-normalized-difference-vegetation-index)、[USGS SAVI](https://www.usgs.gov/landsat-missions/landsat-soil-adjusted-vegetation-index)、[USGS HLS 光谱指数说明](https://lpdaac.usgs.gov/documents/2088/HLS_VI_User_Guide_V2.pdf)。
