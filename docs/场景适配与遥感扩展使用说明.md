# 场景适配与遥感扩展使用说明

2026-09-26。源码目录：`D:\agent\codex\flood-eyes-latest`。

本次交付增加可选择的场景适配洪水识别、三个 SWIR 光谱监测方向、网页入口、GIS 复核图层及独立标注评测。属于实验配方：工程回归与合成案例验证不代表真实地区精度提升。旧 API 和旧批量请求仍默认 `baseline`；新网页表单默认选择明确标注的实验场景适配，用户可以切回原基线。

## 场景规则

用户声明场景；系统不声称已自动识别地貌。混合地貌大区域宜分区评估，不能用整幅影像的一个标签代表所有地物。

| 场景代码 | 光谱与后处理规则 | 需核查事项 |
|---|---|---|
| plain | NDWI，全局与局部阈值融合，保留原形态学设置 | 灾前常水、季节性水面与新增水面 |
| hilly / mountain | NDWI，限制偏移的局部阈值；保留窄水道；可选 DEM 与 AWEI 阴影交叉核查 | 光学地形阴影、陡坡和 DEM 覆盖，当前不做 SAR 地形校正 |
| urban | 优先 MNDWI；波段齐全时用 AWEI_sh 交叉核查；保留较细水域 | 建筑阴影、屋顶、水道尺度与混合像元 |
| coastal | 优先 MNDWI；保留较细水域 | 潮位和风暴潮不可仅凭双时相区分；本版本不自动获取潮位 |
| wetland | NDWI；保留较细水域、不做开闭运算或填洞 | 稻田灌水、湿地物候；不能据此恢复冠层下淹水 |
| arid | 优先 MNDWI，保留原形态学设置 | 湿土、盐碱地、浑水需区域验证 |
| unspecified | NDWI 默认实验配方 | 未声明场景时不推断地貌 |

共同规则：真实绿光和近红外是洪水识别必需输入；MNDWI 额外要求 SWIR1。近红外反射率闸门沿用 0.12，属于待区域标定的经验参数。山地、丘陵、城市、海岸、湿地的窄水道配方关闭开闭运算和填洞，最小连通域为 `min(调用者设置, 9)` 像元；这会保留细水域，也可能保留噪声，必须与原基线共同评估。

`water_index=auto` 时，两个时相都具有 SWIR1 才使用 MNDWI；任一时相缺失则两期统一退到 NDWI 并记录降级，避免混用指数造成假变化。显式指定 `mndwi` 时缺波段直接失败。在线下载仍为四波段；SWIR 需通过本地输入提供。

AWEI_sh = Blue + 2.5×Green − 1.5×(NIR + SWIR1) − 0.25×SWIR2。城市/丘陵/山地候选水体若 AWEI_sh≤0 则进入复核；这是同组光谱的交叉核查，不是独立真值。提供 DEM 时，丘陵/山地候选水体的坡度≥筛查阈值或 DEM 无效邻域也进入复核。坡度不代表淹没水文模型；缺 DEM 时明确降级而不伪造高程。

## 输入与质量

- 推荐已校正到反射率的多波段 GeoTIFF，优先使用明确的 scale/offset 与波段描述。必须检查真实波段、辐射尺度和日期，不能把预览图或不明 DN 当作反射率。既有自动缩放启发式并不替代传感器元数据校验。
- 六波段预设 `s2_6band` 对应 B2/B3/B4/B8/B11/B12。也支持 `B11`/`swir1`、`B12`/`swir2` 描述。无描述时不会仅按通道数猜 SWIR。12 波段（无 B10）与 13 波段分别使用 `s2_l2a_12` 与 `s2_l2a_13`。
- SWIR 的原始分辨率和重采样记录应随输入保留。Sentinel-2 B11/B12 为 20 m，重采样到 10 m 不增加其真实空间细节。
- 场景适配要求米制投影影像；面积使用仿射变换行列式计算，矩形像元不按边长平均值的平方估算。DEM 坡度另外要求北向正置网格，DEM 高程单位应为米。
- 灾后重采样到灾前网格；各波段按有效权重重采样，分类/质量掩膜用最近邻，防止单波段 NoData 混入邻域。单米偏移不会被大坐标相对容差忽略。
- 保留 SCL 同名侧车并核对网格；云影、云、卷云、雪冰和缺陷像元不可当无水。没有 SCL 时仅有光谱云估计并明确提示。网页上传不携带同名侧车，需完整质量层时使用本地批量/API。
- 批量共同有效比例门禁含复核像元排除；未通过门禁返回“数据不足”。可疑像元被排除可能提高有效区内精度，同时降低覆盖率，所以评测必须报告两者。
- 本地影像日期仍为用户声明，不能用请求中的时间窗口作为已核验卫星观测时间。请求、输入、DEM、SCL 和本地外部掩膜/辅助元数据哈希参与成果身份，改变参数或质量输入不能复用旧结果。

## 网页与批量操作

在仓库运行 `python app/main.py`。选择地貌、识别策略，可选 DEM；本地多光谱折叠区上传灾前/灾后两景并选择波段排列。未提供本地对时使用在线获取。

批量 CSV/JSON 增加以下可选字段，旧请求无需修改：

| 字段 | 默认与取值 |
|---|---|
| detection_strategy | baseline / adaptive，默认 baseline |
| water_index | auto / ndwi / mndwi，默认 auto；自定义需 adaptive |
| index_threshold | 默认为自适应；可提供 −1..1 的区域标定指数阈值，需 adaptive |
| slope_threshold_deg | 0..90，默认 15°，为坡度复核阈值 |
| band_order | auto 或显式波段预设 |
| terrain_profile | 上表代码；默认 unspecified |

示例 `jobs.json`（替换本地文件路径，坐标与日期需按实际影像填写）：

```json
[
  {
    "lon": 116.3, "lat": 29.15,
    "pre_start": "2020-05-19", "pre_end": "2020-05-19",
    "post_start": "2020-07-15", "post_end": "2020-07-15",
    "detection_strategy": "adaptive", "terrain_profile": "urban",
    "band_order": "s2_6band", "water_index": "mndwi",
    "min_valid_pct": 50,
    "local_pre": "D:/data/pre.tif", "local_post": "D:/data/post.tif"
  }
]
```

```powershell
python scripts/run_batch.py jobs.json --run --out-dir outputs/scene_jobs
```

山地场景可加 `"terrain_profile": "mountain"`、`"dem_path": "D:/data/dem.tif"`。`index_threshold` 用标定区域确定后，在独立验证事件上验收；本版本不会自动搜索“最优阈值”。

## 成果含义

- `water_mask.tif`：0=有效非水体，1=水体，255=未判定（质量无效或需复核）。
- `change.tif`：0=稳定非水，1=持续水体，2=新增水体，3=退水，255=两期任一时相未判定。新增水面还须排查潮汐、灌溉等非洪灾因素。
- `review.tif` 和 `before_review.tif`：0=未触发本规则复核；1=AWEI 证据冲突；2=陡坡候选；4=辅助证据未覆盖。1/2/4 按位组合，255=光学质量无效。0 不意味着人工已确认正确。
- `valid_mask.tif`：1=参与判定，0=无效或需复核，0 是真实类别；坡度诊断仍见 `terrain_risk.tif`。
- JSON 记录配方版本、实际指数、阈值方法、后处理参数、辅助依据和复核像元数；谱分数不是经过标定的发生概率。

## 新增自动化监测方向

网页“多时相遥感监测”与 `scripts/run_spectral.py` 共享处理：MNDWI 地表水、NDMI 植被水分、NBR 火烧敏感指数，继续支持 NDVI/SAVI/NDWI。结果含逐期指数、相邻差值、共同有效区及摘要，单次运行独立目录。

```powershell
python scripts/run_spectral.py --index ndmi --band-order s2_6band --images pre.tif post.tif --dates 2026-06-01 2026-07-01
```

所有相邻差值为后减前；NBR 差值与通常前减后的 dNBR 符号相反。当前不输出火烧严重度等级、干旱面积或自动因果判断，详见[光谱时序监测使用说明](光谱时序监测使用说明.md)。监测尚未接在线选景和持久化任务队列。

## 如何验证“更精确”

准备与输出严格同 CRS、网格和尺寸的独立真值：0=非水、1=水、255=未知。工具拒绝自动移动真值以及错误类别值。

```powershell
python scripts/evaluate_flood.py --prediction outputs/run/water_mask.tif --reference labels/urban_water.tif --terrain-profile urban --out outputs/urban_metrics.json
```

对原基线和适配结果分别运行；报告 Precision、Recall、F1、IoU、分类覆盖率及全标注水体召回率。后者把未判定的真值水体保留在分母，防止靠扩大复核范围得到虚高成绩。空分母返回 null。应按城市、山地等分层，使用未参与阈值标定的地区/事件；同时检验漏检、误检、面积偏差与可判定范围。当前仓库没有足够的独立真实标注，因此本次不提供真实精度提高百分比。
