# 安装与离线运行（v0.5.0）

本次发布支持 Windows 10/11 x64 精简版与完整版，内置 Python，无需 GPU。包括七类地貌的实验场景适配、六种光谱指数、多时相监测、批量任务与 PDF/GIS 导出。精简版不含 PyTorch/权重；完整版含 CPU PyTorch 和需显式启用的实验 U-Net。两版均不含真实影像缓存，自带影像是合成演示数据。最新状态见 [修复记录](问题修复与完整版交付_20260927.md)。

## 安装和成果位置

运行 `慧眼识灾_安装程序_v0.5.0_精简版.exe`，选择安装目录，再从开始菜单启动。绿色 ZIP 必须完整解压，EXE 和 `_internal` 目录须保持相邻。

默认成果在程序旁的 `outputs`，日志在 `logs/desktop.log`；程序目录不可写时，写入 `%LOCALAPPDATA%/HuiYanShiZai`。可在命令最前面加 `--data-dir D:\洪水成果` 指定可写根目录。卸载保留运行生成的成果、日志和用户权重。

本地 GeoTIFF 计算可离线。图形界面使用本机 127.0.0.1 服务，须系统允许**本程序**接受本机连接；在线底图、选景和卫星下载另需互联网。

## 启动诊断

启动前先检查本机连接，失败会显示判定结论、可执行命令并退出，不再无限等待。诊断命令（在程序目录的 PowerShell 运行）：

```powershell
& '.\慧眼识灾.exe' --diagnose 'D:\新建诊断报告.json'
```

报告路径必须是尚不存在的新文件，父目录须存在。`loopback.status=failed` 时报告里会带 `cause`、`detail`、`remedy` 三个字段：

| `cause` | 含义 | 处置 |
| --- | --- | --- |
| `loopback_timeout` | 回环连接超时，具体组件未确认 | 检查防火墙、安全软件及进程网络策略 |
| `not_listening` | 端口上无人监听 | 程序内部状态异常，不是网络策略问题 |
| `bind_denied` | 绑定端口被拒 | 端口被占用或权限受限 |

### 为什么"本机连接"会被拦

本机回环可能受防火墙、安全软件或其他进程网络策略影响。单凭超时无法确定过滤组件。CPython 的 Windows 回环 socketpair 在连接受限时可能阻塞，因此启动前先做有超时的自检。

已实测确认（证据见 `outputs/release_v0.5.0/net_compare.json`、`net_serve_compare.json`）：

- 同一进程内 `bind → listen → connect`：源码 `python.exe` 0.002 秒成功；打包后的 EXE 4 秒超时。
- 外部进程连接打包 EXE 的监听端口：同样超时；连接 `python.exe` 的监听端口：成功。
- **把 `python.exe` 原样复制改名后运行，同样超时**。字节完全相同、目录相同、只有文件名不同，行为却相反——支持按**可执行文件身份**过滤的可能性，但不能识别具体组件。
- 关闭代理变量、关闭本工具的沙箱隔离，结果都不变；本机防火墙入站策略为 `BlockInbound,AllowOutbound`，且存在针对 `python.exe` 的入站放行规则。

### 放行本程序（需要管理员权限，二选一）

```powershell
# 1) 用随包脚本（会自行提权；撤销加 -Remove）
powershell -ExecutionPolicy Bypass -File .\_internal\scripts\allow_loopback.ps1

# 2) 或手工执行（把路径换成本机实际安装路径）
netsh advfirewall firewall add rule name="慧眼识灾 本机界面" dir=in action=allow protocol=TCP program="C:\...\慧眼识灾.exe" localip=127.0.0.1 remoteip=127.0.0.1 enable=yes profile=any
```

规则限定指定程序、TCP、本地及远端地址 127.0.0.1。仅在确认 Windows 防火墙拦截后使用；放行后需复测，不能保证解决其他组件限制。加 `-DryRun` 可预览程序路径和范围，不提权、不改规则。

> 说明：安装程序以 `PrivilegesRequired=lowest` 安装，不申请管理员权限，因此无法在安装阶段自动写防火墙规则——如确需修改规则，由用户在确认原因后执行。

在线影像下载若报 `schannel: the revocation status is unknown`，属于证书吊销状态无法查询（受限网络访问不到 CRL/OCSP 端点），与影像本身无关；处置见下面的环境变量一节。

## 环境变量

| 变量 | 作用 | 取值与默认 |
| --- | --- | --- |
| `FLOOD_DATA_DIR` | 指定**可写根目录**（成果、日志、用户权重）。等价于命令行的 `--data-dir`，但写进快捷方式或部署脚本后不必改命令；目录不存在会自动创建。 | 任意路径；默认是程序旁的 `outputs`/`logs`，程序目录不可写时退到 `%LOCALAPPDATA%\HuiYanShiZai` |
| `FLOOD_ALLOW_UNSAFE_TLS` | 关闭在线下载的 TLS 证书校验，用于绕开 `schannel: the revocation status is unknown`。**默认关闭**；开启后会把 `tls_verification_disabled: true` 写进成果溯源，请仅在确认网络可信时使用。纯网络不通（连接超时、域名解析失败）时**不要**开启——那不能解决问题，归因日志会明说。 | `1`/`true`/`yes`/`on` 视为开启；默认关闭 |

```powershell
# 成果固定写到 D:\洪水成果，不随程序位置变化
$env:FLOOD_DATA_DIR = 'D:\洪水成果'
& '.\慧眼识灾.exe'

# 仅在确认网络可信时，临时关闭证书校验以完成一次下载（会留痕）
$env:FLOOD_ALLOW_UNSAFE_TLS = '1'
```

另有三个**构建期**变量，普通用户用不到：`FLOOD_PROFILE`（`lite` 默认 / `full`，选择打包档位）、`FLOOD_CONSOLE`（`1` 时保留控制台窗口，便于排查启动问题）、`FLOOD_APP_NAME`（覆盖产物名）。

## EXE 批处理

EXE 的 `--batch` 将其后的参数转交现有批处理命令。建议每个项目指定独立目录，`--run` 会执行该目录队列中的全部等待任务。

```powershell
& '.\慧眼识灾.exe' --data-dir 'D:\洪水成果' --batch 'D:\任务.csv' --run --out-dir 'D:\洪水成果\批次1'
& '.\慧眼识灾.exe' --batch --list --out-dir 'D:\洪水成果\批次1'
```

任务 CSV 必须有 `lon,lat,pre_start,pre_end,post_start,post_end`。离线处理还需 `local_pre,local_post` 的绝对路径；可设置 `terrain_profile`、`detection_strategy=adaptive`、`water_index=auto` 和真实 `band_order`。详见《自动化处理使用说明》。失败或取消任务返回非零退出码；自动化调用可用 `Start-Process -Wait -PassThru` 获取 `ExitCode`。

## EXE 光谱监测与精度评估

```powershell
& '.\慧眼识灾.exe' --spectral --index mndwi --images 'D:\灾前.tif' 'D:\灾后.tif' --dates 2020-01-01 2020-02-01 --band-order s2_6band --out-dir 'D:\新的监测目录'
& '.\慧眼识灾.exe' --evaluate 'D:\预测.tif' 'D:\独立标注.tif' --evaluation-out 'D:\新的评估.json' --terrain-profile plain
```

六波段预设顺序为 B2/B3/B4/B8/B11/B12。MNDWI、NDMI、NBR 必须提供真实 SWIR，不用其他波段冒充。多时相差值均为后减前，NBR 差值不是传统 dNBR。评测栅格须同网格并使用 0/1/255，其中 255 是未知区。

七类地貌配方未经真实区域标定；合成流程测试通过不代表真实洪灾精度提高。需使用独立真实标注，分场景报告精确率、召回率及有效覆盖率。
