# 下载的数据怎么用在本系统上 · 操作指南

> 一句话：**先体检，再对号入座。** 不管从哪下载的数据，第一步都跑：
>
> ```powershell
> python scripts/check_data.py "你下载数据的目录或文件"
> ```
>
> 它会告诉你这是什么数据、能不能直接用、该跑哪条命令。

## 一、决策树（先看这个）

```
你下载的数据是什么？
│
├─ 光学影像（Sentinel-2 / Landsat / 高分 / 资源）
│   │  特征：有红绿蓝+近红外波段，云是白的
│   │
│   ├─ 已经是 4 波段 GeoTIFF（蓝绿红近红外）
│   │     → ✅ 直接用：打开软件 → 页签① → 上传文件
│   │
│   ├─ 3 波段 RGB 图片/影像
│   │     → ✅ 可以上传，但缺近红外，软件会用代理指数，精度下降
│   │
│   ├─ Sentinel-2 SAFE（一堆 JP2 文件）
│   │     → 先用 Copernicus Browser 导出 4 波段 GeoTIFF（见第四节）
│   │
│   └─ 13 波段 Sentinel-2 GeoTIFF
│         → ✅ 直接上传，软件自动取 B2/B3/B4/B8
│
└─ 雷达影像（Sentinel-1 IW GRD，SAFE 格式）
    │  特征：文件夹里有 measurement/*.tiff，黑白图，看不出颜色
    │
    ├─ 有两景（灾前 + 灾后）
    │     → 跑 prepare_s1_sar.py，自动定位洪水 + 提取面积（见第三节）
    │
    └─ 只有一景
          → 也能提取水体范围，但算不了"新增淹没"
```

## 二、光学影像：最简单，直接上传

### 2.1 软件界面操作

1. 双击 `慧眼识灾.exe`（或 `python app/main.py`）
2. 页签 **① 单时相识别**
3. 「或上传卫星影像」→ 选你的 `.tif` / `.png` / `.jpg` / `.npy`
4. 「像元分辨率」填对（Sentinel-2 = 10，Landsat = 30，高分二号 = 0.8/3.2）
5. 点 **🚀 开始识别** → 看面积卡片 → 下载成果包（含 PDF 简报）

**灾前灾后对比**：切页签 ②，分别上传两景，点「开始对比」，会算出新增淹没/退水面积。

### 2.2 命令行方式

```powershell
# 单景
python -c "from src import FloodDetector; print(FloodDetector(mode='baseline').detect(r'D:\数据\xxx.tif').summary_text())"

# 双时相
python -c "from src import FloodDetector; print(FloodDetector(mode='baseline').compare(r'D:\数据\灾前.tif', r'D:\数据\灾后.tif').summary_text())"
```

### 2.3 软件的波段约定

| 波段数 | 软件怎么理解 | 效果 |
|---|---|---|
| 4 波段 | 蓝、绿、红、**近红外** | ✅ 标准 NDWI，精度最好 |
| 3 波段 | 红、绿、蓝 | ⚠️ 用 (绿−红)/(绿+红) 代理指数 |
| 13 波段 | Sentinel-2 L2A 整幅 | ✅ 自动取 B2/B3/B4/B8 |
| 2 波段 | 绿、近红外 | ✅ 可以算 NDWI |
| 1 波段 | — | ❌ 单波段算不了指数 |

> **波段顺序很重要！** 4 波段必须是「蓝绿红近红外」。如果你下载的是「红绿蓝近红外」顺序，
> 结果会偏色、NDWI 出错 —— 先体检，不确定就问我。

## 三、雷达影像（Sentinel-1）：多一步，但能穿云

### 3.1 为什么雷达不能直接上传？

- 光学看"颜色"（NDWI 用绿/近红外），**雷达看"回波强度"**（σ0，单位 dB）
- 水体在光学里是"亮"的，在雷达里是"暗"的（平静水面像镜子，不反射回雷达）
- 雷达数据是 SAFE 格式（一堆 XML + 两个 800MB 的 TIFF），没有仿射变换，靠 GCP 定位
- 所以要先：**标定 → 几何对齐 → 裁剪 → 再提取**

### 3.2 两种用法：软件界面 / 命令行

**【推荐】直接在软件里用**（页签 ③ 雷达 SAR 识别）：

1. 双击 `慧眼识灾.exe` → 切到 **③ 雷达 SAR 识别**
2. 「灾前 SAFE 路径」粘贴你解压后的 `.SAFE` 文件夹路径（如 `F:\遥感河南\S1A_..._20210715...\S1A_....SAFE`）
3. 「灾后 SAFE 路径」粘贴另一景
4. 极化选 `VV`，阈值保持 `-16`，窗口 `4096`
5. 点 **🛰️ 开始雷达识别** → 等 20~60 秒 → 看三联图 + 面积卡片 → 下载成果包

**【命令行】批量/自动化时用**：

```powershell
# 1) 先体检（确认是 Sentinel-1、有两景）
python scripts/check_data.py "F:\遥感河南"

# 2) 自动定位洪水并处理
python scripts/prepare_s1_sar.py `
    --pre  "F:\遥感河南\S1A_..._20210715...\S1A_....SAFE" `
    --post "F:\遥感河南\S1A_..._20210727...\S1A_....SAFE" `
    --pol VV --out data\henan2021 --size 4096
```

脚本自动完成：

1. 解析标定表，把 DN 标定成 σ0(dB)
2. 用 GCP 拟合仿射变换（GRD 没有仿射变换）
3. 把两景投影到同一 UTM 网格（实测两景差 147 米，不对齐河道就错位）
4. 自动找到变化最大的区域（不用你猜洪水在哪）
5. 裁剪 41km×41km 全分辨率窗口 → 提取水体 → 算面积 → 出图

### 3.3 产物长什么样

```
data\henan2021\
├── henan2021_preview.jpg      ← 三联图：灾前 / 灾后 / 变化（直接看这个）
├── henan2021_pre_vv.tif       ← 灾前 σ0(dB)，int16 ×100，带 UTM 坐标
├── henan2021_post_vv.tif      ← 灾后
├── henan2021_pre_overlay.png  ← 灾前水体叠加图（青色=水）
├── henan2021_post_overlay.png ← 灾后水体叠加图
├── henan2021_change.png       ← 变化图：红=新增淹没，绿=退水，青=持续
├── henan2021_post_mask.png    ← 灾后水体掩膜（白=水）
└── samples.json               ← 溯源：景号、时间、极化、阈值、面积
```

### 3.4 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--pol` | VV | VV 对开阔水面更敏感；VH 对植被下淹水更敏感，可两个都试 |
| `--threshold-db` | VV −16 / VH −19 | 水体阈值。结果偏多就调低（如 −18），偏少就调高（如 −14） |
| `--size` | 4096 | 裁剪窗口边长（像元）。想覆盖更大范围就调大（8192 = 82km） |
| `--aoi 经度,纬度` | 自动 | 想固定看某个地点时用，例如 `--aoi 114.42,34.06` |
| `--drop-db` | 3.0 | 变化检测要求的最小变暗幅度 |

## 四、去哪下载数据（免费）

### 4.1 按数据类型选（推荐优先级从高到低）

| 数据 | 网站 | 注册 | 能下什么 | 和本系统怎么配合 |
|---|---|---|---|---|
| **Sentinel-1 + Sentinel-2**（一站式） | https://browser.dataspace.copernicus.eu/ | 免费注册 | 光学 + 雷达，可在线预览、导出 4 波段 GeoTIFF | ⭐ 首选。光学导出后直接上传页签①；雷达下 SAFE 用页签③ |
| **Sentinel-1 雷达**（下载快） | https://search.asf.alaska.edu/ | Earthdata 账号（免费） | IW GRD/VH/VV，按 AOI/时间/轨道搜索 | ⭐ 你 `F:\遥感河南` 那份就是这类数据 |
| **Sentinel-1/2**（免注册） | 本仓库 `scripts/fetch_real_samples.py` | **不用** | 自动抓 10km 窗口的 4 波段 GeoTIFF | 最省事，一条命令出样本 |
| **Landsat 8/9** | https://earthexplorer.usgs.gov/ | 免费注册 | 30m 光学，B2/B3/B4/B5 = 蓝绿红近红外 | 下载后直接上传（分辨率填 30） |
| **高分/资源系列** | https://data.cresda.cn/ ｜ https://www.cresda.cn/ | 需申请 | 国内高分辨率光学/雷达 | 下载后按 4 波段上传（注意波段顺序） |

### 4.4 Copernicus Browser 导出 4 波段 GeoTIFF（光学最佳实践）

1. 打开 https://browser.dataspace.copernicus.eu/ ，注册/登录
2. 左上角选 **Sentinel-2 L2A**，搜索地点/日期（挑云少的）
3. 找到目标景，点右上「下载」
4. 选 **Analytical** 或 **Bands**，勾选 `B02` `B03` `B04` `B08`
5. 下载 GeoTIFF（10m）→ 直接拖进软件页签①

### 4.5 ASF 下载 Sentinel-1（雷达最佳实践）

1. 打开 https://search.asf.alaska.edu/ ，用 Earthdata 账号登录
2. 左上「Search」→ 输入地点/绘制 AOI → 选日期范围
3. 左侧筛选：**Dataset = Sentinel-1**、**Beam Mode = IW**、**Product Type = GRD_HD**
4. 结果列表里挑两景（灾前 + 灾后，最好同一轨道号），勾选 → 「Download」
5. 下载的是 `.zip`（含 `.SAFE`）→ 解压 → 用软件页签③

> 小技巧：同一轨道的两景几何差异最小（轨道号差约 175 是 12 天周期）。你那份数据两景轨道号
> 38787 / 38962，差 175，正是同一轨道，所以对齐后河道不会错位。

### 4.6 用本仓库免注册抓取（最省事）

```powershell
# 看看内置了哪些洪涝事件
python scripts/fetch_real_samples.py --list

# 抓某个事件（自动挑 AOI 窗口云量最低的灾前/灾后景）

# 想加新事件：编辑 scripts/fetch_real_samples.py 顶部的 EVENTS 字典

## 五、常见问题

| 问题 | 原因 / 解决 |
|---|---|
| 上传后识别出一大片水，明显不对 | 波段顺序不对（尤其"红绿蓝"当成了"蓝绿红"）；先用 `check_data.py` 确认 |
| 提示"缺少近红外波段" | 3 波段 RGB；换成 4 波段产品，或接受精度下降 |
| 面积数字不对 | 「像元分辨率」填错了。S2=10m，Landsat=30m，GF-2=3.2m |
| 影像太大，上传卡住 | 先用 GDAL/QGIS 裁一小块；或雷达用 `--size 4096` |
| 雷达跑完结果偏多/偏少 | 调 `--threshold-db`：偏多调低（−18），偏少调高（−14） |
| 雷达两景对不上、河道错位 | 脚本已自动对齐；如果仍偏，检查两景是不是同一轨道（轨道号差约 175） |
| 云太多什么都看不见 | 换雷达（Sentinel-1），这就是雷达存在的意义 |
| 不知道数据是什么 | `python scripts/check_data.py "路径"` |
