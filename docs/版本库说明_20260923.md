## 为什么会有这份说明

归档副本 `06_v0.3.1_发布_20260915\源码\flood-eyes\.git` 是一个**残缺的仓库元数据**：
`packed-refs` 仍然指向提交 `6b17c445…`（main）、`bd7577a2…`（tag v0.3.1）、
`b2e0f05c…`（tag baseline-v0.3.1-dev），但 `.git/objects` 只剩 20 个对象，
上述提交对象都不在里面。因此任何 git 命令都报：

```
$ git status

```

结论：**旧副本无法提交、无法回放历史**（不是本次改动造成的，归档时就已如此）。
本轮 v0.4.0 需要一个能真正提交、能追溯的版本库，所以重建。
