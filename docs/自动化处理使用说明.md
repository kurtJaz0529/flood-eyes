# 遥感自动化处理使用说明

适用于 v0.4.0 源码。启动界面：

```powershell
python app/main.py --host 127.0.0.1 --port 7860
```

打开 `http://127.0.0.1:7860/`，展开“批量处理（上传 CSV / JSON，排队执行）”。上传文件或直接编辑表格内容，点“导入并校验”，确认逐行结果后点“开始处理队列”。任务历史会保留在 `outputs/automation/jobs.sqlite`；选中任务编号并刷新即可查看日志与下载成果包。也可以点“加入最小演示任务”检查流程，合成样本不能用于真实精度评估。

## 批量输入

CSV 第一行是列名；JSON 为对象数组。必须提供 `lon,lat,pre_start,pre_end,post_start,post_end`，日期格式为 `YYYY-MM-DD`，灾前窗口必须早于灾后窗口。可选列：`size,terrain_profile,max_cloud_pct,min_valid_pct,local_pre,local_post,dem_path`。坐标使用 WGS84 经度、纬度；`size` 为影像窗口边长（64–4096 像元）。

```csv
lon,lat,pre_start,pre_end,post_start,post_end,size,terrain_profile,max_cloud_pct,min_valid_pct
116.30,29.15,2020-05-08,2020-06-05,2020-07-10,2020-07-30,512,plain,35,50
```

不填 `local_pre/local_post` 时，系统按请求的地点与时间检索并下载 Sentinel-2 影像；两列都填时使用本地 GeoTIFF，并在成果中注明“未核验观测日期”。坏行会单独报错，其他有效行仍可入队。网络下载需要可访问数据服务；如果云量或共同有效观测不达标，任务会失败并说明“数据不足”。

## 地形地貌与 DEM

`terrain_profile` 可填 `unspecified`（未声明）、`plain`（平原/河湖）、`hilly`（丘陵）、`mountain`（山地）、`urban`（城市）或 `coastal`（沿海感潮）。它只决定报告里的复核提示，不自动改变水体分类。山地要重点复核阴影与坡面，城市要复核建筑阴影，沿海要结合潮位核对时相；平原和丘陵仍要复核浑水、植被与地形遮挡。

本地 DEM 可选。提供有地理参考的 GeoTIFF 后，系统在影像网格上计算坡度，把坡度 ≥15° 的像元标为“需复核”，输出 `terrain_risk.tif`（0 低、1 需复核、255 未评估）。影像网格需要北向正置的米制投影；NoData、DEM 覆盖范围外与无法可靠求坡度的边缘都记为未评估。坡度标记不是淹没判据，也不能替代现场核查。

## 命令行

```powershell
python scripts/run_batch.py jobs.csv                 # 只导入并校验
python scripts/run_batch.py --run                     # 执行所有等待任务
python scripts/run_batch.py --list                    # 查看历史
python scripts/run_batch.py --retry <任务编号>           # 重试失败/取消/中断任务
python scripts/run_batch.py --cancel <任务编号>          # 取消等待任务或请求阶段边界取消
python scripts/run_batch.py --recover                 # 显式恢复确实中断的任务
```

界面和命令行可共用任务库，但要指向同一个输出目录：界面默认为 `outputs/automation`，命令行需加 `--out-dir outputs/automation`。任务执行为串行。网络请求进行中不能即时取消；恢复命令会避开仍持有执行锁的进程，近期显示为运行中的任务也暂不恢复。

每个任务的成果在 `outputs/automation/runs/<任务编号>/bundle.zip`。其中 `water_mask.tif` 的 0/1/255 分别为陆地/水体/未知；`valid_mask.tif` 的 0/1 为无效/有效；`change.tif` 的 0/1/2/3/255 为未变/持续水体/新增水体/退水/未知。变化面积只在灾前与灾后共同有效区域统计。成果另含 PNG、JSON 和 PDF 简报，记录输入与处理警告。若原影像缺少可靠地理参考，系统会跳过 GIS 栅格并写明原因。

当前版本按点位窗口处理。区域多边形、跨景拼接、长时间序列与光学/SAR 自动切换属于后续实施包；不同地貌的识别精度尚需用独立真值样本评估。
